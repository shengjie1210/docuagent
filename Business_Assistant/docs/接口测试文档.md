# Business_Assistant 接口测试文档

> Base URL: `http://localhost:8080`
> 所有接口（除注册/登录）都需要在 Header 加：`Authorization: Bearer {token}`

---

## 1. 认证模块

### 1.1 注册
```
POST /api/auth/register
Content-Type: application/json

{
  "username": "zhangsan",
  "password": "123456"
}
```

**成功响应**：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "token": "eyJhbGci...",
    "username": "zhangsan"
  },
  "traceId": "a1b2c3d4"
}
```

**失败响应**（用户名已存在）：
```json
{
  "code": 409,
  "message": "用户名已被注册",
  "data": null
}
```

---

### 1.2 登录
```
POST /api/auth/login
Content-Type: application/json

{
  "username": "zhangsan",
  "password": "123456"
}
```

**成功响应**：同注册，返回 token。

---

## 2. 文档管理模块

> 以下接口都需要 Header：`Authorization: Bearer {token}`

### 2.1 上传文档
```
POST /api/document/upload
Content-Type: multipart/form-data

表单字段：
  file = 选择一个 .txt / .md / .pdf / .docx 文件
```

**成功响应**：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": 1,
    "filename": "AGENTS.md",
    "fileType": "md",
    "size": 1056,
    "summary": null,
    "tags": null,
    "chunkCount": null,
    "status": "ready"
  }
}
```

**失败响应**：
- 文件太大：`{"code":400,"message":"文件大小不能超过 20MB"}`
- 格式不对：`{"code":400,"message":"仅支持 PDF / Word / Markdown / TXT 格式"}`

---

### 2.2 文档列表（分页）
```
GET /api/document/list?keyword=AGENTS&page=1&size=10
```

**成功响应**：
```json
{
  "code": 200,
  "data": {
    "total": 1,
    "records": [
      {
        "id": 1,
        "filename": "AGENTS.md",
        "fileType": "md",
        "size": 1056,
        "status": "ready"
      }
    ],
    "page": 1,
    "size": 10
  }
}
```

---

### 2.3 文档详情
```
GET /api/document/1
```

---

### 2.4 文档原文
```
GET /api/document/1/content
```

**成功响应**：
```json
{
  "code": 200,
  "data": "# AGENTS.md\n...文档原文..."
}
```

---

### 2.5 删除文档
```
DELETE /api/document/1
```

## 3. 对话管理模块

### 3.1 新建对话
```
POST /api/conversation/create
Content-Type: application/json

{

}
```

---

### 3.2 对话列表

```
GET /api/conversation/list
```

---

### 3.3 删除对话

## 4. AI 对话模块

### 4.1 流式问答（SSE）
```
POST /api/chat/stream
Content-Type: application/json

{
  "conversationId": 1,
  "message": "这个文档是关于什么的？"
}
```

**返回**：SSE 事件流，逐字推送：

```
event: message
data: 这

event: message
data: 个

event: message
data: 文

event: done
data: {"answer":"这个文档是关于...","sources":[{"docId":1,"filename":"AGENTS.md","content":"..."}]}
```

---

## 5. 完整测试流程

```
1. POST /api/auth/register  -> 拿到 token
2. Header 加 Authorization: Bearer {token}
3. POST /api/document/upload  -> 上传 AGENTS.md
4. POST /api/conversation/create  -> 拿到 conversationId
5. POST /api/chat/stream  {"conversationId":1,"message":"这个文档讲什么？"}
   -> 看 SSE 流式回答
6. POST /api/chat/stream  {"conversationId":1,"message":"能详细说说吗？"}
   -> AI 记得上一轮
7. GET /api/conversation/1/messages  -> 看完整历史
8. GET /api/document/list  -> 看文档列表
```

## 6. 错误码对照表

| code | 含义 |
|------|------|
| 200 | 成功 |
| 400 | 参数错误（文件太大、格式不对等） |
| 401 | 未登录 / Token 失效 |
| 403 | 无权限访问该资源 |
| 404 | 文档/对话不存在 |
| 409 | 用户名已注册 |
| 500 | 服务器内部错误 |
| 503 | AI 服务不可用 |
