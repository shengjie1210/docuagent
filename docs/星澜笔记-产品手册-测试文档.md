# 星澜笔记（StellarNote）产品手册

> 版本：V2.4.1
> 发布日期：2026 年 9 月 15 日
> 维护团队：星澜实验室 · 北京

## 一、产品定位

星澜笔记是一款面向知识工作者的本地优先 Markdown 笔记应用。
核心差异点在于"先本地、后云端"——所有笔记默认加密保存在用户设备上，
同步是可选行为，且端到端加密，服务器侧无法阅读原文。

## 二、版本与定价

- **个人版（Free）**：永久免费，最多 3 个笔记本，单文件 5MB 上限。
- **专业版（Pro）**：68 元 / 年，无笔记本数量限制，支持 PDF 导出与 Wi-Fi 直连同步。
- **团队版（Team）**：199 元 / 人 / 年，最少 5 人起购，包含共享知识库、权限审计、SSO 登录。
- **教育版**：在校师生凭 .edu 邮箱可免费申请 Pro 授权，有效期 1 年，可续期。

## 三、核心功能

1. **本地加密**：使用 AES-256-GCM 加密本地库，密钥由用户口令派生（PBKDF2, 600000 次迭代）。
2. **Markdown 编辑**：支持 GFM 语法、数学公式（KaTeX）、图表（Mermaid）、嵌入图片。
3. **跨端同步**：支持 macOS / Windows / iOS / Android / Web 五端，协议为端到端加密的 WebDAV。
4. **全文搜索**：基于 Lunr.js 的本地索引，支持中文分词与拼音搜索。
5. **双链笔记**：使用 [[双括号]] 语法建立笔记之间的链接，自动生成图谱视图。
6. **版本历史**：每篇笔记保留最近 30 个版本，可一键回滚。

## 四、系统要求

- macOS 12 及以上 / Windows 10 21H2 及以上 / iOS 15 / Android 10
- 内存 ≥ 4GB，磁盘 ≥ 200MB 可用空间
- 网络：仅在同步时需要；离线模式全功能可用

## 五、已知问题（截至 V2.4.1）

- Windows 下高 DPI 缩放时 Mermaid 图谱偶发模糊，计划在 V2.5 修复。
- 移动端大文件（>2MB）首次打开需等待 1~2 秒索引，属预期行为。
- 团队版 SSO 目前仅支持 Azure AD 与 Google Workspace，企业微信/飞书预计 2027 Q1 上线。
